# SIMPLY~
SIMPLY is a  compact, custom-designed 8-key macropad with a rotary encoder, built using the Seeed Studio XIAO RP2040.
This project makes the things simple , portable  and customize for productivity and everyday use. this macropad is built in STASIS (organised by hackclub).

---

## Features of our macropad 

*  8 programmable mechanical keys
*  Rotary encoder support (e.g., volume control, scrolling etc)
*  Powered by RP2040 microcontroller
*  Fully customizable firmware 
*  Custom PCB design

---

## Hardware used -

* Microcontroller: Seeed Studio XIAO RP2040
* Switches: 8 ×  Mechanical switches
* Encoder: 1 × Rotary encoder with push button
* PCB: Custom designed (KiCad)
